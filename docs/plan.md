# 작업 플랜 · 진행 로그

Netbitrage 소개 사이트의 목표, 구성, 진행 상황을 한곳에 추적한다.
정보 공개 경계는 [`content-policy.md`](./content-policy.md), 배포는 [`deployment.md`](./deployment.md) 참고.

마지막 업데이트: 2026-06-10

---

## 0. 목표

무위험 차익거래(롱·숏 양방 헤지)와 상장숏(신규 상장 단기 SHORT) 자동매매 프로그램을
**소개·홍보**하고 방문자를 **메일 문의**로 전환하는 별도 정적 사이트.

- 기존 계측기기 사이트(`NetbiX_homepage`, 도메인 `netbitex.kro.kr`)와 **완전히 분리** 운영.
- **소스코드 비공개**, **상장숏 전략 디테일 비공개** (개념 수준만 노출).
- 정적 사이트 → 웹에서 직접 실행/다운로드 제공하지 않음. 전환 목표는 메일 문의.

## 1. 결정 사항

| 항목 | 결정 |
|---|---|
| 위치 | `c:\project\Netbitrage_homepage` 신규 폴더 (독립) |
| 디자인 | 새 다크 테마(딥 네이비 + 민트/시안 액센트), 트레이딩 톤 |
| 페이지 | index / arbitrage / short / contact (4 페이지) |
| 문의 | Web3Forms 메일 전송 (백엔드 없음) |
| 사용 방식 | 다운로드/웹 실행 없음. 메일 문의로만 연결 |

## 2. 구성

```
index.html        랜딩 (히어로 + 두 프로그램 + 강점 + 위험고지 + CTA)
arbitrage.html    무위험 차익거래 (무위험 차익거래란 / 왜 되는가 / 양방 헤지 직관 / 자동화 흐름 / 꼬리 리스크)
short.html        상장숏 (단기 과열 회귀 개념 / 패턴 / 특징(추상) / 리스크)
contact.html      문의 폼 (관심 프로그램 선택, ?program= 프리필)
css/style.css     디자인 시스템 (변수 + 컴포넌트 + 반응형)
js/main.js        네비 토글 / 스크롤 등장 / 문의 폼 전송 / 연도 갱신
```

## 5. 변경 로그

### 2026-08-26 — 수익률(성과) 페이지 추가
- `performance.html` 신규 생성: 상장숏·무위험 차익거래 두 전략의 실측 성과를 다크테마 요약 카드로 노출.
- 각 전략의 상세 리포트 원본을 `reports/` 로 복사해 사이트에 포함하고 iframe 임베드 + 새 창 링크 제공.
  - `reports/listing_short_report.html` (상장숏 실거래 기록: 승률 87.5%, 누적 +224.87 USDT 등)
  - `reports/listing_arbitrage_report.html` (무위험 차익 포워드 백테스트: 복리 +17.23%, 정합 기준 +143.4%)
- 비공개 정책 준수: 차익 리포트의 내부 파일 경로(`trade_log.csv` 절대경로)·프로젝트명(`listing_arbitrage`)을
  Netbitrage 브랜드 표기로 정리. 전 페이지 네비/푸터에 "수익률" 링크 추가.
- 과거 성과 ≠ 미래 수익 고지와 측정 방식(투입마진 대비 / 슬리피지·수수료 미반영) 명시.

### 2026-06-10 — 초기 구축
- `listing_arbitrage/docs`, `listing_short/docs` 를 참고해 두 전략을 소개하는
  4페이지 다크테마 정적 사이트 신규 생성.
- 소스코드/전략 핵심 분기 비공개 원칙을 `content-policy.md` 로 문서화하고 전 페이지에 적용.
- `docs/` 는 **내부 문서**로, 정식 호스팅 시 공개 디렉터리에서 제외 권장 (deployment.md 참고).
- Web3Forms 기반 메일 문의 폼, 투자 위험 고지 배너 포함.

### 2026-06-10 — 수치 표기 허용 + Web3Forms 키 확정
- 운영자 결정으로 **일반 운용 수치 표기 허용**. 무위험 차익거래에 파라미터 섹션(1:10 / 10배 / 갭 3% /
  익절 1.5% / 손절 80% / 1일)과 헤지 다이어그램 수치(자본 C, 증거금 C/10) 추가.
- 상장숏에 레버리지 2배·3분할·격리마진 표기 추가. **시총/이동평균 청산 분기 등 핵심 엣지는 계속 비공개.**
- 문의 폼 Web3Forms access key 를 운영 키(`57cc4300-…`)로 확정.

### 2026-06-10 — "상장따리" → "무위험 차익거래" 리브랜딩
- 운영자 요청으로 프로그램 명칭을 **상장따리 → 무위험 차익거래**로 변경 (전 페이지 네비/카드/푸터/문의 라벨).
- arbitrage 페이지에 **"무위험 차익거래란?"** 개념 섹션 신설: 차익거래 정의, **양방 매매(롱·숏 동시)**,
  시장 비효율성(가격 괴리) 수익화, 방향성 무노출 = 무위험 직관을 명시.
- URL/파일명(`arbitrage.html`)·내부 program id(`arbitrage`)는 호환 위해 유지.
