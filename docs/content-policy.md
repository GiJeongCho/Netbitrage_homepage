# 콘텐츠 공개/비공개 경계 가이드

이 사이트의 **최우선 원칙은 소스코드 유출 방지와 상장숏 핵심 분기 로직 비공개**다.
콘텐츠를 추가/수정할 때 아래 경계를 지킨다.

마지막 업데이트: 2026-06-10

> 정책 변경(2026-06-10): 운영자 결정으로 **레버리지·진입/청산 임계치 등 일반 수치는 표기 허용**.
> 무위험 차익거래는 파라미터(자본비율 1:10, 레버리지 10배, 갭 3%, 익절 1.5%, 손절 80%, 1일)를 공개한다.
> 상장숏도 레버리지(2배)·분할 차수(3분할)·격리마진 등 일반 수치는 공개하되,
> **시가총액/이동평균 기반 청산 분기, 돌파 트리거 배율, 공지 파싱 규칙 등 핵심 엣지는 계속 비공개.**

---

## 1. 공개해도 되는 것

- 두 프로그램이 **무엇을 노리는가**
  - 무위험 차익거래: 신규 상장 시 거래소 간 가격 괴리를 롱·숏 양방으로 잡는 헤지 차익
  - 상장숏: 신규 상장 직후 단기 과열의 평균 회귀에 베팅하는 SHORT
- 무위험 차익거래의 **롱·숏 양방(델타 중립) 헤지로 방향성·꼬리 리스크를 차단**한다는 직관과 그림
- "감지 → 진입 → 모니터링 → 청산" 의 **완전 자동화, 24시간 운용, 리스크 관리**라는 강점
- **일반 운용 수치 (허용)**
  - 무위험 차익거래: 자본비율 1:10, 레버리지 10배, 진입 갭 3%, 익절 1.5%, 손절 80%, 최대 보유 1일
  - 상장숏: 레버리지 2배, 3분할 진입, 격리마진
- **투자 위험 고지** (오히려 적극적으로 노출)

## 2. 노출하면 안 되는 것

- **상장숏 핵심 엣지(분기) 로직**
  - 시가총액 기준값, 이동평균 크로스/추세배율 기반 청산 모드 분기
  - 3차 진입의 돌파 트리거 배율·타이밍 산식, 익절 트리거 정밀 조건
  - 공지 파싱 규칙(정규식), 포지티브/네거티브 키워드
- **구현/구조 일체**
  - 소스코드, 파일/모듈 구조, config 키 이름, API 엔드포인트, 라이브러리 스택
- **거래소 계정/API 키 등 운영 비밀**

## 3. 표현 톤 가이드

- 상장숏의 **청산 모드 분기**는 "코인의 성격과 추세 조건에 따라" 수준으로만 추상화한다
  (시총·이동평균·배율 수치는 쓰지 않는다).
- 수익률·승률 등 **성과 수치를 단정적으로 제시하지 않는다** (수익 보장 오해 방지).

## 4. 자가 점검 체크리스트 (배포 전)

- [ ] 상장숏 페이지에 시가총액·이동평균·돌파 배율 등 핵심 분기 산식이 없는가
- [ ] 코드 스니펫, 파일 경로, config 키, 정규식이 노출되지 않았는가
- [ ] 수익 보장으로 읽힐 문구가 없는가 (위험 고지가 포함됐는가)
- [ ] 원본 프로젝트(listing_arbitrage / listing_short) 내부 용어/구현이 새어나오지 않았는가
